# ระบบควบคุมครุภัณฑ์และเช็คสต็อก QR Code (สำนักปลัด อบต.ฝางคำ)

ระบบบริหารจัดการและตรวจนับครุภัณฑ์ครบวงจรด้วย QR Code พัฒนาด้วย **Laravel 13**, **SQLite / PostgreSQL**, **OpenSpout (.xlsx)** และ **BaconQrCode (Vector SVG)**

## ความสามารถหลัก
- **ทะเบียนคุมครุภัณฑ์สำนักปลัด (194 รายการ)** พร้อมรายการ **รอจัดสรรตำแหน่ง (123 รายการ)** นำเข้าจากไฟล์ Excel ต้นฉบับ (`storage/app/seed/ตารางครุภัณฑ์69_สำนักปลัด.xlsx`)
- **ระบบ QR Code ติดตาม & พิมพ์สติกเกอร์ขนาด 1.5 × 1.5 ซม.** จัดหน้ากระดาษสติ๊กเกอร์ A4 อัตโนมัติ (40 / 30 / 24 / 21 / 65 / 10 ดวงต่อแผ่น และ Thermal) พร้อมระบบเว้นช่องว่างเริ่มต้นและจูนระยะขอบ
- **สแกน QR Code เช็คสต็อก** ผ่านกล้องมือถือ/เว็บแคม อัปโหลดรูป QR หรือเครื่องอ่านบาร์โค้ด USB และ **โหมดสแกนต่อเนื่องเข้ารอบตรวจนับประจำปี**
- **แจ้งซ่อมบำรุง / โอนย้ายผู้รับผิดชอบ / จำหน่ายครุภัณฑ์** พร้อมบันทึกประวัติการเคลื่อนไหวครบทุกขั้นตอน
- **นำเข้า / ส่งออกรายงาน Excel (.xlsx)** แยกตามปีงบประมาณ หมวดหมู่ และตำแหน่งผู้รับผิดชอบ

## การติดตั้งและเริ่มต้นใช้งาน
```bash
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed
php artisan storage:link
php artisan serve
```
